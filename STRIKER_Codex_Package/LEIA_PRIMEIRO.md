# STRIKER — Instruções para iniciar no Codex

Este pacote contém tudo o que está aprovado para desenvolver o site da Striker Soluções Digitais.

## Como usar

1. Crie ou abra o repositório onde o site será desenvolvido.
2. Extraia esta pasta na raiz do repositório, preservando sua estrutura.
3. Abra o Codex nesse repositório.
4. Envie ao Codex a mensagem abaixo.

> Leia primeiro `STRIKER_Codex_Package/LEIA_PRIMEIRO.md` e depois leia integralmente `STRIKER_Codex_Package/documentacao/STRIKER_PACOTE_TECNICO_IMPLEMENTACAO.md`. Audite o repositório e todas as referências e assets do pacote antes de editar qualquer arquivo. Em seguida, execute o PROMPT MESTRE localizado no final do documento técnico. Implemente o site completo, valide tecnicamente e compare screenshots em 1440px e 390px com as respectivas referências. Não invente projetos, clientes, métricas ou depoimentos. Não considere o trabalho concluído apenas porque o projeto compilou.

## Estrutura

- `documentacao/`: especificação, textos, regras e prompt mestre.
- `referencias/desktop/`: seis grupos visuais desktop aprovados.
- `referencias/mobile/`: seis grupos visuais mobile aprovados.
- `assets/`: logo horizontal, símbolo da marca e fotografia real do fundador.

## Atenção

- As imagens são referências visuais, não devem ser usadas como uma única imagem de fundo no site.
- Textos, botões, cards, formulários e navegação devem ser implementados em HTML/CSS/JavaScript.
- O desktop e o mobile possuem composições próprias.
- O retrato correto do fundador é `assets/rafael-gomes-fundador.png`.
- Não use retratos gerados por IA.
- Os projetos e o depoimento continuam como placeholders honestos até a entrega do conteúdo real.
- O WhatsApp oficial é `5554999102656`.

## Resultado esperado

Um site responsivo, funcional e visualmente próximo das referências, com menu, FAQ, formulário, WhatsApp, acessibilidade, SEO básico, validação técnica e comparação visual obrigatória.
